# SDD-005: Точки входа в сценарии

## Поведение

Стартовая страница показывает чат без сценарных кнопок. Свободный ввод отправляет вопрос через `POST /v1/jobs`. Ответ появляется через WebSocket с HTTP-резервом.

Три сценарные кнопки убраны: стартовая страница работает как простой чат. О вопросах доступа агент отвечает только по найденным источникам. Форма создания заявки отключена, поскольку подтверждённый порядок оформления доступа не найден.

Чтение тестовой Jira через MCP остаётся доступным в `live`-режиме с токеном из серверного `.env`. Токен не включается в спецификацию, репозиторий или ответы API.

## Границы

Демо-роль в отключённом прототипе Jira-заявки не является производственной авторизацией. История чата в распределённом режиме следует SDD-008.

## Приёмка

1. На странице есть только чат; сценарных кнопок и формы Jira-заявки нет.
2. Вопрос создаёт задание через существующий API; статусы и ошибки показываются в ленте сообщений.
3. Вопрос о доступе не создаёт Jira-заявку и не выдаёт выдуманный внутренний порядок за регламент Авито.
