# SDD-044. Редактирование вопроса и остановка ответа

Карандаш доступен, пока задание в очереди или в обработке. Он открывает текст вопроса в поле ввода и сразу отправляет команду остановки. После ответа сервера редактор остаётся открытым. Enter или кнопка отправки передают изменённый вопрос. Крестик и Escape закрывают редактор и возвращают прежний черновик с цитатами. Отменённая правка не возобновляет генерацию. Отправка текста без изменений закрывает редактор.

В основном и мини-чате активный ответ можно остановить квадратной кнопкой. Сервер помечает задание как `failed` с причиной «Остановлено пользователем». Воркер проверяет статус и токен аренды каждые 300 мс. При остановке он отменяет контекст HTTP-запроса к модели. Запись результата требует действующего токена аренды, поэтому поздний ответ не меняет состояние задания.

## API

| Маршрут | Результат |
| --- | --- |
| `POST /v1/jobs/{id}/stop` | `200` и текущее состояние задания. Уже завершённое задание сохраняет свой результат. |
| `POST /v1/jobs/{id}/edit` с `{"query":"изменённый вопрос"}` | `202` и новое задание с прежним сценарием. Заголовок `Location` указывает на новое задание. |

Маршруты проверяют ключ API, если он настроен, и владельца задания по сессии и роли. Редактирование применяется к личному чату. Сервер атомарно сохраняет замену и помечает исходное задание полем `superseded_at`. История и контекст модели исключают заменённые записи. Новый вопрос проходит обычную очередь.

## Проверка

Интеграционные тесты с `TEST_DATABASE_URL` проверяют права на остановку и редактирование, отмену соединения с тестовым HTTP-сервером модели, защиту от позднего результата и замену вопроса в истории. Браузерный сценарий с подменой API проверяет карандаш, Escape и отправку исправленного текста.
