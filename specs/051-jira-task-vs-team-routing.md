# 051 — Личные задачи и состав команды в чате

Оператор воспроизвёл ошибку на стенде. На вопрос «Какие задачи у меня?» воркер дважды выводил состав команды. Список в разделе «Мои задачи» работает через отдельный API.

Планировщик модели выбирает Jira для личных задач и сроков даже без названия сервиса или ключа. Профиль команды нужен для получения Jira account ID. Список участников возвращается только при запросе об участниках, ролях или личности наставника. Если пользователь просит и задачи, и сведения о наставнике, планировщик сохраняет оба намерения. История помогает разрешать ссылки в коротких продолжениях. Самостоятельный новый вопрос определяет текущую тему.

Первый вызов планировщика получает вопрос без истории. Повторный вызов получает историю, если модель вернула `needs_recent_context` и есть недавние реплики. Так смена темы не зависит от того, что обсуждалось непосредственно перед вопросом.
