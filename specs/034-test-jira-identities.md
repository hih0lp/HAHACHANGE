# SDD-034: Jira accountId для трёх тестовых ролей

Тестовый чат имеет роли `intern` (стажёр 1), `intern2` (стажёр 2) и `mentor` (наставник). Роль чата `mentor` входит в сервис команды под ID `approver`. Сервис команды получает сопоставление своих ID с Jira `accountId` из JSON-переменной `TEAM_JIRA_ACCOUNTS_JSON` в отдельном тестовом `.env`; код не содержит конкретных accountId.

Для `intern` сохраняется `accountId` единственного исполнителя в снимке `fixtures/mock/jira.json`: `712020:dac8b504-c5af-48c6-961f-501520b7615d`. Для остальных тестовых пользователей создаются уникальные идентификаторы только внутри имитатора:

| Пользователь сервиса команды | Тестовый Jira accountId | Задачи в текущем снимке |
| --- | --- | --- |
| `intern` | `712020:dac8b504-c5af-48c6-961f-501520b7615d` | SCRUM-7 |
| `intern2` | `mock-928916bb-945a-43f7-99bd-d3d52b995bc9` | Нет |
| `approver` | `mock-6aa38b7e-c2ca-44fb-90fc-d8c8b5a4b50d` | Нет |

Тестовая конфигурация:

```dotenv
TEAM_JIRA_ACCOUNTS_JSON={"intern":"712020:dac8b504-c5af-48c6-961f-501520b7615d","intern2":"mock-928916bb-945a-43f7-99bd-d3d52b995bc9","approver":"mock-6aa38b7e-c2ca-44fb-90fc-d8c8b5a4b50d"}
```

Эти mock ID не выдаются за реальные Jira-аккаунты и не добавляют задачи в `jira.json`. После изменения переменной нужно пересоздать тестовый контейнер `team-access`, чтобы он обновил профили в собственной БД; API и mock Jira читают их через существующий MCP. Запрос личных задач для стажёра 2 и наставника должен вернуть пустой список по проекту из JSON, а не задачи стажёра 1 или ошибку о несопоставленном аккаунте. Календарная авторизация этой правкой не меняется.

Проверка: получить профиль каждой из трёх тестовых ролей через сервис команды, проверить три разных ID и вызвать личный список задач. Рабочий `.env` и рабочий стек не меняются.

Результат на `bobby-mocks` 14 ноября 2026 года: после обновления только тестового `.env` и пересоздания `team-access` запрос к тестовой БД подтвердил три разных `jira_account_id`, совпадающих с таблицей выше. В чате под `intern2` и `mentor` вопрос о назначенных задачах завершился ответом «В проекте SCRUM нет задач, назначенных вам». Задача SCRUM-7 им не приписана. Контейнеры рабочего стека и рабочий `.env` не менялись.
