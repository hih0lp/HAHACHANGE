# Спецификация: ответ модели без карточек документов

## Требование

При вопросе через веб-страницу пользователь видит статус задания и итоговое сообщение модели. Если модель включила ссылки на источники в Markdown-формате, они отображаются внутри сообщения как кликабельные ссылки. Найденные фрагменты, их оценки и отдельные карточки документов на странице не отображаются.

## Контракт

1. Форма вопроса отправляет `POST /v1/jobs` и показывает ответ после события `completed` по WebSocket либо после опроса `GET /v1/jobs/{id}`.
2. Текст сообщения добавляется в DOM как текст. Только ссылки вида `[название](https://адрес)` превращаются в элементы `a`; HTML из ответа не исполняется.
3. `sources` в ответе API остаётся доступным для программного клиента, но веб-страница его не отображает. Поисковый API также остаётся доступным агенту.
4. Вопросы о доступах могут показывать действие для тестовой заявки в Jira; оно не является документом-источником.

## Проверка

- Тест веб-страницы подтверждает запрос к `/v1/jobs`, вывод `job.answer`, поддержку ссылок и отсутствие кода вывода `job.sources` и поисковых фрагментов.
- `go test -coverpkg=./... ./...` и `go vet ./...` проходят перед сборкой образа.
