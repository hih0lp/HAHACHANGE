# SDD 027. Веб-интерфейс Бобби

React 18, TypeScript и Vite заменяют HTML-страницы Go. Go отдаёт приложение на прежних адресах `/` и `/onboarding`, а также на `/tasks`. Ссылки `/forms/{id}` по-прежнему переводят в чат. В Docker Node собирает статику из lock-файла, Go и nginx отдают её с того же адреса, что и API. Прокси Vite поддерживает HTTP и WebSocket.

## Экраны

| Экран | Компонент и поведение | Источник | Состояния |
|---|---|---|---|
| Чат | Поле вопроса, быстрые действия, сообщения, ссылки рядом с фактом. Enter отправляет, Shift+Enter переносит строку. HTML из ответа выводится как текст | `/v1/jobs`, WebSocket, резервный GET задания, `/v1/chat/history`, `/v1/deadline-notifications` для демо-роли | Приветствие, отправка, очередь, подготовка ответа, результат, пустой ответ, ошибка, переподключение, ручная проверка после тайм-аута |
| Профиль | Диалог с входом, выходом, переключением демо-роли и необязательным ключом API. На телефоне открывается снизу. Escape закрывает диалог и возвращает фокус | `/v1/team-access/session`, `/v1/demo/role`, `/v1/scenarios/login` | Демо, вход, ошибка, активный аккаунт, истекшая сессия |
| Адаптация | Карточка цели, текущий статус, подтверждённые пункты и следующий шаг. ID сценария сохраняется для текущей личности браузера | `/v1/scenarios`, `/v1/scenarios/{id}`, действия `advance` и `access-requests` | Нет данных, старт, восстановление, доступ нужен, заявка на согласовании, доступ подтверждён, источник недоступен |
| Заявка | Каталог и форма в чате. Поля из схемы, ресурс и право из каталога текущей команды, проверка сервером до отдельного подтверждения. При закрытии фокус возвращается к ссылке либо к полю чата | `/v1/forms`, `/v1/forms/resources`, `/v1/forms/{id}`, `validate`, `submit` | Загрузка, пустой каталог, ошибка, проверка, подтверждение, повтор с тем же ключом, ID и статус ответа |
| Мои задачи | Карточки с источником, статусом, датой и ссылкой. Источники обновляются независимо. Время показывается в МСК, дедлайн Jira отображается как календарная дата | `/v1/tasks/jira`, `/v1/gitlab/reminders`, `/v1/calendar/reminders` | Загрузка, результат, пустой список, недоступный источник |

Существующие демо-история и оповещения продолжают использовать серверную cookie и роль. Вход через профиль открывает историю, привязанную к проверенному ID аккаунта внутри той же cookie. Для HTTP клиент передаёт `X-Bobby-Account: 1` с Bearer-токеном. Для WebSocket клиент передаёт токен в первом сообщении после подключения. Доступ к Jira привязан к Jira account ID из проверенного профиля. Jira показывает ближайшие дедлайны, календарь — события в диапазоне маршрута напоминаний. Оба источника используют мок-интеграции из SDD-032. Страница задач не запрашивает отключённый GitLab.

Для повторного подтверждения после сетевой ошибки браузер хранит исходную форму и ключ идемпотентности в пределах вкладки и аккаунта. API остаётся источником ID и статуса заявки. Правила и роли демо относятся к прототипу.

## Дизайн

Композиция новая. Отдельный образ Бобби перерисован в SVG. Веб-типографика использует Arial по [публикации AvitoTech](https://habr.com/ru/companies/avito/articles/691262/). [Публикация о дизайн-системе](https://habr.com/ru/companies/avito/articles/543450/) задаёт подход к общим компонентам и состояниям. Figma и экспорт AKITA для этого проекта отсутствуют. Значения в `frontend/src/styles.css` — локальные токены прототипа.

| Стиль или компонент | Реализация | Основа |
|---|---|---|
| Текст и заголовки | Arial, `--text`, `--text-small`, `--title`, `--display` | Гарнитура из статьи, шкала прототипа |
| Фон и разделители | `--white`, `--canvas`, `--neutral`, `--line` | Прототип |
| Действия и акценты | `--action`, `--action-hover`, `--focus`, `--brand-*`, `--mint`, `--lavender`, `--peach` | Цветовое направление Авито, значения прототипа |
| Кнопки и поля | `.button`, `.field-stack`, `.composer`, размер `--control`, `--radius-*` | Прототип. Обводка фокуса, состояния наведения, нажатия, ожидания и недоступности |
| Карточки, сообщения, уведомления | `.card`, `.pill`, `.notice`, `--space-*`, `--error-*` | Прототип. Статус выражен текстом, длинные названия и ссылки переносятся |
| Навигация, иллюстрация, иконки | `visuals.tsx`, широкая панель и диалог меню на узком экране | SVG прототипа, Бобби по присланному изображению |

## Запуск и проверка

```sh
npm --prefix frontend ci
npm --prefix frontend run build
npm --prefix frontend run test:coverage
npm --prefix frontend exec -- playwright install chromium
npm --prefix frontend run test:browser
go test -count=1 -coverpkg=./... -coverprofile=coverage-new.out ./...
go tool cover -func=coverage-new.out
go vet ./...
```

Для Vite используйте `npm --prefix frontend run dev`. По умолчанию прокси ожидает API на `http://127.0.0.1:18000`. Задайте `BOBBY_API_URL`, если API слушает другой адрес. Для браузерного теста с установленным Chrome задайте `BOBBY_CHROME`. Скриншоты сохраняются в `frontend/test/screenshots` или в папку из `BOBBY_SCREENSHOTS`. Для работы интеграционных тестов Go задайте `TEST_DATABASE_URL` на отдельную тестовую базу PostgreSQL.

Для живого прогона поднимите распределённый стек по README, войдите как демо-стажёр, откройте каталог из чата, выберите ресурс и право, введите обоснование, проверьте форму и подтвердите заявку. Сверьте ID и статус с сервисом доступа. Для приёмки можно измерять время до следующего шага, долю успешных действий и долю обращений, завершённых без ручной помощи.
