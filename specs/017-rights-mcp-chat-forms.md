# SDD-017: MCP сервиса прав и форма внутри чата

## Причина и контракт

SDD-015 открывала форму в новой вкладке. JWT хранился в `sessionStorage` вкладки чата, поэтому новая вкладка могла показать «Форма недоступна». В этом сценарии пользователь заполняет и подтверждает форму в чате. Старые ссылки `/forms/{id}` перенаправляют в чат с параметром формы.

Сервис `access-rights` предоставляет собственный Streamable HTTP MCP на `/mcp`. Каталог Бобби получает инструменты из этого сервиса через `tools/list`: список ресурсов, проверку права, список форм, схему формы и проверку значений. Командный MCP содержит только профиль и состав команды. Бобби выбирает инструменты моделью, без словаря фраз в worker. JWT передаётся MCP-клиентом, модель его не видит. HTTP API сервиса остаётся независимым контрактом для других клиентов и моделей.

## Подтверждение и запись

Ссылка `form_url` в ответе Бобби отображается в чате как кнопка, которая загружает актуальную JSON Schema и UI Schema. Поля строятся по схеме. Сначала пользователь видит заполненные значения, затем отдельной кнопкой подтверждает отправку. На каждую попытку подтверждения создаётся ключ идемпотентности; повтор той же попытки сохраняет ключ.

Записывающий MCP-инструмент `rights_form_submit` доступен у сервиса прав на `/mcp/confirm`. Этот каталог не передаётся модели. Только HTTP-обработчик подтверждения в приложении вызывает его после нажатия пользователем кнопки внутри чата. Сервис прав выполняет проверку схемы, версии формы, JWT и идемпотентности и создаёт заявку либо общее обращение. Сервис возвращает ID и статус; чат показывает их только после успешного ответа. Права возникают после отдельного решения согласующего.

## Проверка

Проверить `tools/list` обоих MCP-каталогов, отсутствие инструмента отправки в каталоге модели, открытие формы в чате без новой вкладки, повтор старой ссылки, ошибку схемы, подтверждение заявки, повтор с тем же ключом и отказ стажёру при попытке согласовать собственную заявку. Проверить живой ответ Бобби о форме, составе команды и правах.

Ссылку на форму в ответе Бобби интерфейс показывает видимой акцентной ссылкой с реальным `href=/forms/{id}`. Нажатие открывает форму внутри карточки чата; обычный переход по ссылке также остаётся рабочим через старый маршрут. Это позволяет увидеть и скопировать ссылку, в том числе в сохранённой истории.

Перед генерацией ответа модель классифицирует, требуется ли пользователю форма, и выбирает `form_id` из текущего каталога `rights_forms_list`. Сервер проверяет выбранный ID и URL по каталогу и сам возвращает ссылку; при неоднозначном выборе показывает доступные формы. Выдача ссылки не зависит от того, сформирует ли модель Markdown в обычном ответе. Классификация описана правилами о смысле запроса, без списка фраз пользователя.
