# SDD-035. Напоминания перед дедлайном задачи

Сканер проверяет незавершённые задачи Jira для настроенных демоучёток стажёров. Исполнителя и наставника текущей команды определяет через каталог команды. [Срок задачи](043-exact-mock-jira-deadlines.md) берёт из данных Jira.

Демо-конфигурация задаёт 10 минут для стажёра и 5 для наставника через `REMINDER_INTERN_MINUTES_BEFORE` и `REMINDER_MENTOR_MINUTES_BEFORE`. Неположительное значение выключает соответствующий вид уведомления. Сканер проверяет сроки каждые 15 секунд. В окне от порога до дедлайна он сохраняет одно уведомление для сочетания получателя, вида, задачи и срока.

Стажёр получает `intern_deadline`, наставник — `mentor_deadline`. По истечении срока новые карточки не создаются, а интерфейс скрывает просроченные карточки. Ссылка показывается, если Jira вернула безопасный адрес задачи.
