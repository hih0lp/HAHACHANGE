# SDD-035: напоминания перед дедлайном задачи

В тестовом стеке Бобби создаёт отдельные сохранённые уведомления для стажёра 1 и наставника по незавершённым задачам, назначенным Jira `accountId` стажёра 1. Время окончания задачи берётся из `due_date` в редактируемом `jira.json`: это начало следующего дня в `REMINDER_TIMEZONE`, поскольку Jira-снимок содержит дату без времени. Никакое другое время окончания из названия или описания задачи не выводится.

Тестовая конфигурация задаёт `REMINDER_INTERN_MINUTES_BEFORE=10` и `REMINDER_MENTOR_MINUTES_BEFORE=5`. Оба значения читаются из окружения, а не из текста вопроса или фиксированного ключа задачи. Если значение неположительно, соответствующее уведомление выключено. При попадании в окно `[due_at - minutes, due_at)` API сохраняет не более одного уведомления на получателя, вид, задачу и срок. Стажёр получает вид `intern_deadline`, наставник текущей команды — `mentor_deadline`. Ранее сохранённые виды `intern_48h` и `mentor_24h` больше не показываются. Если сканер или браузер были выключены в момент порога, уведомление доставляется при следующей проверке до срока; после срока не создаётся.

Сканер и интерфейс проверяют новые уведомления каждые 15 секунд, поэтому показ в открытом чате может отставать от порога на время двух опросов и сетевых задержек. Уведомления сохраняются в БД и доступны после повторного открытия чата. Схема БД допускает новые виды уведомлений как на чистом запуске, так и после миграции существующего тестового тома. Ссылка карточки берётся из HTTPS `url` задачи в JSON через read-only REST мока; внутренний адрес контейнера не выдаётся пользователю. При отсутствии безопасной ссылки карточка показывает название без ссылки. Совместимый маршрут `/v1/reminders` не меняет своего отдельного часового окна и не создаёт карточки в чате. Конфигурация, JSON Jira, сервис команды, формы и календарь остаются отдельными источниками.

Проверка: границы `10:00` и `5:00` минут до срока, отсутствие уведомления раньше окна и после срока, фильтрация завершённых и чужих задач, отсутствие дублей по уникальному ключу, чтение уведомлений по роли и основные вопросы к тестовому чату. Текущий снимок SCRUM-7 просрочен на 14 ноября 2026 года, поэтому живую доставку именно этой задачи без временной замены даты подтвердить нельзя; временная замена для теста должна быть возвращена к исходному снимку.
