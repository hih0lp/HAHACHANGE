# SDD-036: доступ к тестовому Бобби через Tailscale

Изолированный проект `bobby-mocks` публикует только свой gateway на `100.105.236.12:18001` в сети Tailscale и на `127.0.0.1:18001` на сервере. API, worker, моки Jira/Calendar, базы данных и сервисы команды/прав не публикуются через Tailscale. Рабочий Compose-проект не изменяется.

Для текущего тестового сервера `.env` задаёт `BOBBY_LOCAL_PORT=18001`, `BOBBY_REMOTE_BIND=100.105.236.12`, `BOBBY_REMOTE_PORT=18001`, `BOBBY_TEAM_PORT=18082` и `BOBBY_RIGHTS_PORT=18083`. Compose продолжает брать адрес и порт из конфигурации, а не из кода. На другом сервере оператор заменяет Tailscale IP и при необходимости порты. Проверять доступ нужно с компьютера в той же сети Tailscale по `http://100.105.236.12:18001/`.

Проверка 14 ноября 2026 года: после пересоздания только gateway рабочие `api` и `worker` остались запущены; gateway показал два binding: `100.105.236.12:18001` и `127.0.0.1:18001`. HTTP GET по Tailscale-адресу вернул 200 и с сервера, и с отдельного клиента. Ссылка доступна участникам той же сети Tailscale.
