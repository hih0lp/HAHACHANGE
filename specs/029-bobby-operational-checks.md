# Проверки доступности Бобби

Две локальные проверки выполняются каждые два часа. После сбоя автоматизация повторяет проверку один раз и сообщает о подтверждённой проблеме.

- `python -X utf8 scripts/check-bobby-health.py` проверяет критические контейнеры Docker, состояние узла Tailscale и HTTP на его адресе, авторизованный API истории и прохождение синтетического задания Бобби от HTTP через очередь до ожидаемого ответа. Проверка создаёт отдельную демо-сессию и сохраняет синтетическое задание.
- `python scripts/check-gitlab-mcp.py` проверяет вход демо-стажёра, каталог из 14 инструментов и чтение списка проектов через адрес GitLab MCP у worker.

Проверка Tailscale запускается на сервере. Для подтверждения маршрута, ACL и доступа извне нужна дополнительная проба с другого узла tailnet. Локальные автоматизации требуют доступного хоста. Проверки не выводят токены, содержимое конфигурации и пользовательские ответы.
