# SDD-043. Сроки задач Jira и карточки в чате

Мок Jira читает срок из `fixtures/mock/jira.json`. Необязательное `due_at` в формате RFC 3339 задаёт точное время и имеет приоритет перед `due_date`. Если указана только дата, срок считается началом следующего дня в настроенной часовой зоне. Некорректное значение вызывает ошибку чтения фикстуры. Срок доступен в MCP и в REST-поиске для напоминаний.

[Правила расчёта и получатели](035-minute-deadline-pings.md) общие для сроков обоих форматов. Раздел «Мои задачи» получает задачи в часовом окне `REMINDER_HOURS_BEFORE` через `GET /v1/tasks/jira`. Стажёр видит свои незавершённые задачи, наставник — задачи стажёров команд, где он назначен наставником. Сервис определяет пользователя по командному токену.

Чат получает снимки карточек через `/v1/deadline-notifications/ws`. Первым сообщением клиент отправляет командный токен и API-ключ. Сервер определяет получателя по подтверждённому профилю и отправляет его снимок при подключении и после каждого прохода сканера. После обрыва клиент переподключается. HTTP-маршрут уведомлений доступен для совместимости.

Активное напоминание отображается красной карточкой над прокручиваемой областью чата. Кнопка «Закрыть уведомление» сохраняет ID карточки в браузере для этой роли. Карточка остаётся скрытой после переподключения и перезагрузки. Новый срок может создать карточку с новым ID.
