# SDD-019: MCP каталога команд внутри сервиса

## Цель

Каталог команд и сервис прав остаются независимыми HTTP-сервисами. Каждый предоставляет собственный MCP для клиентов с моделями. Бобби не владеет адаптером каталога команд и не содержит бизнес-правил команды.

## Контракт

В режиме `team` сервис `team-access` сохраняет HTTP API входа, профиля и участников и предоставляет Streamable HTTP MCP `/mcp` с инструментами `team_profile` и `team_members`. MCP вызывает HTTP API того же сервиса с JWT пользователя. Сервис прав сохраняет собственный MCP и отдельно проверяет членство через HTTP каталога команд. Авторизация и границы видимости одинаковы для HTTP и MCP.

Worker получает URL обоих MCP-сервисов из конфигурации и запрашивает их каталоги через `tools/list`. API-ключ Бобби не передаётся этим сервисам; для вызова используется только JWT пользователя. Выбор инструмента остаётся за моделью, без словаря фраз, привязки ресурса к инструменту или привязки формы к сценарию.

Старый `/team-mcp` в API Бобби удаляется. Другие модели и приложения могут использовать HTTP API и MCP сервисов независимо от Бобби.

## Проверка

Проверить состав MCP-каталогов на обоих контейнерах, чтение своей команды и `404` для чужой, запрос формы через MCP сервиса прав, а также живой ответ Бобби после прямого подключения к MCP каталога команд. Проверить, что старый маршрут API недоступен и текущий диалог с выбором ресурса продолжает работать.
