# SDD-007: Напоминания стажёру о сроках задач

## Сценарий

Стажёр открывает чат AI-buddy. Если задача тестового проекта Jira назначена его `accountId`, не завершена и до конца дня её срока осталось не более X часов, чат показывает напоминание и ссылку на задачу. Проверка повторяется каждую минуту через WebSocket; HTTP даёт резервное чтение.

## Источник и конфигурация

- Источник задачи, исполнителя, статуса и даты срока — Jira Cloud REST `/search/jql` с полями `summary,status,assignee,duedate`.
- `REMINDER_INTERN_ACCOUNT_ID` задаёт одного демо-стажёра. Здесь нет входа пользователя и персональной авторизации; экран подходит только для одиночного учебного стенда.
- `REMINDER_HOURS_BEFORE` — X, по умолчанию 24 часа. `REMINDER_TIMEZONE` — часовой пояс даты Jira, по умолчанию `Europe/Moscow`.
- `duedate` Jira содержит только дату. Срок считается истёкшим в 00:00 следующего календарного дня выбранного часового пояса. Напоминание действует в промежутке `[due_at-X, due_at)`.
- Задачи с `statusCategory.key=done`, другим исполнителем или без срока исключаются. При выключенной Jira или без `accountId` напоминания выключены; интерфейс явно сообщает об этом.

## Контракты

- `GET /v1/reminders` возвращает `{enabled, reminders:[{id,key,summary,due_at,url}], message?}`.
- `GET /v1/reminders/ws` отправляет тот же снимок при подключении и каждую минуту. При установленном `API_KEY` клиент первым сообщением передаёт `{"api_key":"..."}`; ключ не передаётся в URL. Проверка Origin остаётся стандартной.
- Браузер показывает в чате ссылку и срок один раз за открытую вкладку. При обрыве WebSocket опрашивает HTTP.

## Границы

Напоминания работают в открытой веб-странице. Нет фоновой отправки во внешние каналы, учётных записей стажёров и постоянного хранилища доставок. При нескольких инстансах API такую функцию нужно перенести на общий планировщик и реальную авторизацию.

## Проверка

Тест: напоминание появляется только в заданном окне для назначенной и незавершённой задачи; после срока исчезает. Проверены HTTP-защита ключом, начальный снимок WebSocket и отсутствие формы создания заявки на главной странице.
