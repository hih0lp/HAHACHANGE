# SDD-037: отправка формы доступа по HTTP тестового стенда

Тестовый Бобби доступен по `http://100.105.236.12:18001/`. В этом контексте браузер не предоставляет `crypto.randomUUID()`: при проверке полей встроенной формы доступа возникает ошибка `Проверьте значения полей: crypto.randomUUID is not a function`, и запрос подтверждения не отправляется.

Обе пользовательские формы, которые создают ключ идемпотентности в браузере — встроенная форма в чате и форма сценария первой задачи — генерируют его через `crypto.getRandomValues()` из 16 случайных байт. Ключ создаётся один раз на попытку подтверждения и сохраняется при повторном запросе после сетевой ошибки. Никакие значения полей, имена пользователей или ID заявок в генераторе не зашиты. Если криптографический генератор недоступен, интерфейс показывает ошибку и не отправляет заявку без ключа.

После успешного ответа `POST /v1/forms/{id}/submit` встроенная форма в чате показывает точный текст `Заявка успешно отправлена!`. Сообщение об успехе не появляется при ошибке HTTP или проверки полей. Сервер по-прежнему возвращает ID и статус заявки в JSON для других клиентов; сам факт отправки не выдаёт право доступа. Ошибка в отдельном сценарии первой задачи исправляется тем же способом генерации ключа, его собственное сообщение о статусе сценария остаётся прежним.

Проверка: тест HTML обеих страниц, работа ключа в HTTP-контексте без `randomUUID`, подтверждение встроенной формы и сохранение прежних проверок схемы, версии, авторизации и идемпотентности. Обновляется только отдельный тестовый стенд и ветка.
