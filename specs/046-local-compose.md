# SDD-046. Локальный запуск Бобби

`docker compose -f compose.local.yml up --build --wait` поднимает отдельный
проект `bobby-local`. Шлюз собирает фронтенд из исходников. API и воркер
используют PostgreSQL, Redis, Kafka, Qdrant, TEI и Ollama из той же сети.
Jira, календарь, GitLab и мессенджер работают как независимые MCP-сервисы.
При первом запуске Ollama скачивает модель, TEI готовит эмбеддинги, а API
индексирует учебную базу знаний. Демоучётки настроены в Compose.
Для Qwen3 8B и четырёх параллельных запросов Ollama Docker Desktop рекомендуется
выделить не менее 16 ГБ памяти. При 12 ГБ локальный `model-init` завершился
ошибкой нехватки памяти: требовалось 9,5 ГиБ при доступных 8,4 ГиБ.

Для приёмки проверьте запуск с новыми томами, вход в чат, ответ Ollama и
вызовы MCP Jira, календаря, GitLab и мессенджера. Через Бобби проверьте
поиск по учебной базе и историю «Каталога».
