# SDD-061. Запуск скачанного репозитория

После Download ZIP или git clone пользователь запускает из корня
`docker compose up --build --wait --wait-timeout 1200`. Нужны Docker
с Compose, интернет для первой загрузки и память для Qwen3 8B.

`compose.yaml` поднимает отдельный проект `bobby-download`. Образы Go
и React собираются из исходников в контейнерах. Сборка загружает
AvitoTech Playbook по закреплённой ревизии и SHA-256, поэтому соседний
каталог и .env для этого сценария не нужны. Фикстуры и миграции включены
в репозиторий. Предыдущий поисковый запуск находится в `compose.search.yml`.

Ollama скачивает `qwen3:8b` и применяет temperature=0, top_k=20,
top_p=0.95, repeat_penalty=1 из `deploy/Modelfile.qwen3-8b`.
Контекст 8192, один параллельный запрос. Модель прогревается при первом
вопросе. Тип модели сохраняется при недостатке памяти, ошибка остаётся
видимой. API и мессенджер ждут readiness эмбеддингов. Образ эмбеддингов
выбирается для AMD64 или ARM64 по архитектуре Docker.

Проверка включает разбор Compose без .env, сборку в распакованной копии,
создание новых томов, запуск API, моков и индекса. После запуска
`docker compose exec ollama ollama list` должен показывать qwen3:8b.
Проверяются HTTP шлюза, роли, источники и ответ Бобби. Фактически
пройденные этапы фиксируются в отчёте задачи.

## Проверка 16 ноября 2026

Проверено на Docker Desktop / Linux AMD64 из отдельной копии файлов
репозитория без .git, .env, node_modules и соседнего Playbook. Новые тома
созданы проектом bobby-repo-check, порты проверки 18021/28105.
Сборка Go, React и образа эмбеддингов прошла; запуск с --wait завершился
успешно. Playbook загружен по закреплённой ревизии: 606 фрагментов в индексе.
Проверены вход всех трёх деморолей, Jira, GitLab, календарь и формы.
Исправлено устаревшее сопоставление Jira: intern=demo-intern,
intern2=demo-intern2, approver=demo-approver.

Ollama загрузила Qwen3 8B (5,2 ГБ), ollama show подтвердил параметры.
Прямой запрос к модели завершился ответом за 22 секунды; на время этой
проверки остановлен только контейнер эмбеддингов проверочного проекта,
чтобы освободить память при работающих параллельно старых стендах.
После восстановления эмбеддингов запрос через очередь Бобби
«Какие у меня задачи в Jira?» завершился успешно с четырьмя задачами
стажёра 1. Нативный запуск на Mac ARM64 в этой проверке не выполнялся.
