# SDD-010: Jira выключена по умолчанию

Если `JIRA_MODE` не задан, сервис запускается с Jira в режиме `off`. Агент не вызывает Jira MCP и не получает тестовые задачи. Маршрут создания моковой заявки не регистрируется. Вопросы о конкретных задачах без подтверждённого источника получают ответ о недостатке данных.

`JIRA_MODE=live` разрешает обращения к тестовой Jira только с корректными URL, проектом, типом задачи, email и API-токеном. `JIRA_MODE=mock` допускается лишь как явный демонстрационный выбор.

Приёмка: конфигурация без `JIRA_MODE` имеет режим `off` и проходит валидацию без секретов; маршрут заявки отсутствует; явный `mock` остаётся доступным для тестов; неверный режим и `live` без учётных данных отклоняются.
