# SDD-010: Jira выключена по умолчанию

Если `JIRA_MODE` не задан, сервис запускается с Jira в режиме `off`. Агент не вызывает Jira MCP и не получает задачи. Маршрут создания заявки не регистрируется. Вопросы о конкретных задачах без подтверждённого источника получают ответ о недостатке данных.

`JIRA_MODE=live` разрешает обращения к Jira только с корректными URL, проектом, типом задачи, email и API-токеном. Значение `mock` отклоняется при запуске. Тестовые HTTP-серверы и заглушки используются только в автоматических тестах.

Приёмка: конфигурация без `JIRA_MODE` имеет режим `off` и проходит валидацию без секретов; маршрут заявки отсутствует; `mock`, неверный режим и `live` без учётных данных отклоняются.
