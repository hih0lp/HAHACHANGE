# 049 — Ollama на NVIDIA GPU

Для запуска на Windows с Docker Desktop и WSL 2 добавьте `-f compose.local.gpu.yml` к действующему набору файлов Compose. Оверлей передаёт NVIDIA GPU контейнеру Ollama. Для применения достаточно пересоздать сервис `ollama` командой `up -d --no-deps ollama` в том же проекте Compose.

После запуска выполните пробную генерацию и проверьте столбец `PROCESSOR` через `ollama ps`. Проверка готовности контейнера сама по себе не подтверждает использование GPU.

На стенде `bobby-local` модель `qwen3:4b` загрузила 37 из 37 слоёв на RTX 5060 Ti. Пробная генерация ответила HTTP 200, `ollama ps` показала `100% GPU`. Страница чата также ответила HTTP 200.
