# SDD-009: Роль Бобби и обычные вопросы

## Цель

AI-buddy представляется как Бобби, ИИ-помощник стажёра. Он помогает с задачами и онбордингом, но также отвечает на общие вопросы, объясняет понятия и помогает с кодом без требования найти документ для каждого ответа. Системная роль не содержит названия проекта, тестовых задач или предположений о составе подключённых сервисов.

## Правила ответа

1. Системное сообщение задаёт имя, роль и границы. Вопрос пользователя, фрагменты базы знаний и данные Jira передаются отдельно как данные.
2. Для внутренних процессов, людей, прав и конкретных задач Бобби использует только релевантные документы и данные подключённых сервисов; если подтверждения нет, сообщает об этом. Ссылки ставятся рядом с такими фактами.
3. Для общих вопросов Бобби отвечает знаниями модели. Нерелевантные фрагменты поиска не цитируются; ссылки не обязательны. Изменчивые факты без свежей проверки помечаются как неопределённые.
4. Ошибка поиска документов не мешает общему разговору. При ней Бобби не выдаёт непроверенную внутреннюю информацию.
   Временный запуск с `ALLOW_DEGRADED_STARTUP=true` пропускает ожидание Qdrant и индексацию, чтобы чат работал через доступную LLM при сбое Docker. Обычный запуск сохраняет проверку зависимостей.
5. Общие вопросы со словом «задача» и вопрос «Что такое Jira?» не вызывают Jira MCP. Для списка требуется упоминание Jira/Джиры вместе с задачами, статусом или тикетами; ключ вида `SCRUM-5` вызывает чтение конкретной задачи.

## Проверка

- Тест LLM-запроса проверяет отдельное системное сообщение с именем Бобби и пользовательское сообщение с контекстом документа.
- Тест общего вопроса при недоступном поиске проверяет успешный ответ без источников.
- Существующие тесты Jira MCP и RAG остаются зелёными.
