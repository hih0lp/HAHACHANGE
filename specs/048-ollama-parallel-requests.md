# 048 — Параллельные запросы к Ollama

Локальный Compose задаёт `OLLAMA_NUM_PARALLEL=1` для простоты настройки. Это
лимит одновременных запросов к одной модели в Ollama; остальные запросы ждут
своей очереди. Значение можно изменить в `compose.local.yml`.
Kafka-воркер Бобби также берёт по одному заданию за раз. При контексте 8192
параллельная обработка увеличивает объём памяти, необходимый модели. На Docker
с 12 ГБ памяти Qwen3 8B не прошла прогрев при четырёх параллельных запросах:
требовалось 9,5 ГиБ свободной памяти при доступных 8,4 ГиБ. При одном
параллельном запросе прогрев прошёл успешно.
