# Учебный онбординг Бобби

В демопроекте SCRUM задачи хранятся в имитации Jira. Начните с просмотра
назначенных задач и согласуйте первый шаг с наставником команды.

Обсуждения по каталогу проходят в учебном мессенджере, в группе «Каталог».
Расписание и занятость наставника доступны через учебный календарь.

Учебный GitLab содержит репозиторий Bobby Playbook. Для запроса доступа к
учебному ресурсу используйте форму «Заявка на доступ» в Бобби.
