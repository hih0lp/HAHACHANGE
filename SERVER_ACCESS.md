# Подключение к тестовому серверу

1. Подключитесь к сети Tailscale, в которой доступен сервер.
2. В терминале выполните:

   ```bash
   ssh hackchange_collab@100.105.236.12
   ```

3. В PowerShell сервера перейдите в тестовый проект:

   ```powershell
   cd D:\HackChange\workspace\avito-rag-mock-services
   ```

Если вы уже в той же сети Tailscale, тестовый чат доступен напрямую: `http://100.105.236.12:18001/`. Запасной способ — SSH-туннель в отдельном терминале:

```bash
ssh -L 18001:127.0.0.1:18001 hackchange_collab@100.105.236.12
```

После подключения откройте `http://127.0.0.1:18001/` в браузере. Для выхода из SSH-сессии выполните `exit`. Нужны права входа для `hackchange_collab` и доступ к указанной сети Tailscale.
