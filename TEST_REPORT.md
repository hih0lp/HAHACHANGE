## React-интерфейс Бобби, 13 ноября 2026

- TypeScript и production-сборка Vite прошли. Linux-бинарник Go собран с отключённым CGO.
- Playwright и Chrome прошли четыре сценария на 360, 768 и 1440 CSS px. Использованы синтетические ответы API. Проверены вход и восстановление адаптации, WebSocket и резервный опрос, пустой ответ и тайм-аут, серверная ошибка проверки формы, двойное подтверждение, потеря связи с повтором после перезагрузки, частичный отказ источников, МСК, возврат фокуса и отсутствие горизонтальной прокрутки.

- Полная сборка Docker и прогон на распределённом стенде с LLM, Jira, GitLab и календарём остаются открыты. Скриншоты браузерного прогона показывают синтетические данные.

Команды воспроизведения и настройка `TEST_DATABASE_URL` описаны в [SDD-027](specs/027-bobby-react-web.md).

## Команды

```shell
go test -count=1 -coverpkg=./... -coverprofile=coverage-new.out ./...
go tool cover -func=coverage-new.out
go vet ./...
```

## Результат

- Все Go-тесты прошли.
- Суммарное покрытие прикладного Go-кода: **90,0%** по `go tool cover -func`.
- `go vet ./...` прошёл.
- JavaScript веб-страницы прошёл синтаксическую проверку Node.js.
- Dockerfile запускает Go-тесты при сборке и отклоняет образ при покрытии ниже 90%.

Веб-страница и ответы модели проверяются автоматическими тестами в `cmd/server/web_test.go`, `cmd/server/main_test.go`, `cmd/server/jira_mcp_test.go` и `cmd/server/error_paths_test.go`. Временный профиль `coverage-new.out` создаётся на сервере указанной командой и не добавляется в Git.

Запуск обновлённого контейнера и ручной запрос к модели ожидают восстановления Docker Desktop на сервере.
