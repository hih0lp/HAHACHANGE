# Отчёт об автоматических тестах

Проверена ревизия `b1beea7a27b37d7b49d9d56e354d981900f079ca`
15 ноября 2026 года на Windows amd64. Использовались Go
1.26.1, Node.js 25.0.0, npm 11.6.2, PowerShell 7.6.9, Chrome
157.0.8103.51, PostgreSQL 17.5 и Redis 7.4. Версии JavaScript-зависимостей
зафиксированы в `frontend/package-lock.json`.

## Результаты

| Область | Покрытие | Объём |
| --- | ---: | --- |
| Прикладной Go, исполняемые строки | **82,13%** | 4 342 из 5 287 |
| Прикладной Go, операторы по `go tool cover` | **82,1%** | Пакеты сервера, MCP и прикладных библиотек |
| React / TypeScript, исполняемые строки | **88,23%** | 975 из 1 105 |

Обе области превышают требование кейса в 80% строк. Цель команды около
90%. Бэкенд пока ниже этой цели. Проценты Go и фронтенда приведены
отдельно, поскольку инструменты измеряют строки разными способами.

Прошли тесты Go и `go vet`, проверка TypeScript, сборка Vite, 7 модульных тестов
фронтенда и три браузерных набора Playwright. Основной браузерный набор
включает ширины 360, 768 и 1440 px. Отдельные наборы проверяют
редактирование данных, конфликт версий, подтверждение формы,
сохранённую квитанцию и восстановление сессии.

## Воспроизведение

Из корня репозитория при запущенном Docker:

```powershell
pwsh -File scripts/test-coverage.ps1
```

Скрипт поднимает временные контейнеры PostgreSQL и Redis с отдельными
loopback-портами. Будут установлены зависимости фронтенда из lock-файла.
Чтобы выполнить замер на той же версии Chrome, задайте `BOBBY_CHROME`
путём к её исполняемому файлу. Без этой переменной Playwright
устанавливает свой Chromium.
Для проверки только Go используйте `-GoOnly`. Параметр `-OutputDir`
задаёт каталог отчётов. По умолчанию это `bobby-test-coverage` в системном
временном каталоге.

- `go.cover`, `go-functions.txt` и `go.html` содержат стандартный профиль
  покрытия Go, разбиение по функциям и подсветку кода.
- `go-lines.json` сопоставляет начала исполняемых AST-операторов с
  блоками из стандартного профиля. Каждая строка учитывается один раз
  и считается покрытой, если соответствующий блок выполнился.
- `frontend/summary.json` содержит покрытие React и TypeScript по
  исходным строкам после преобразования source maps. Запуски браузера
  объединяются, а исполняемые модули проекта без обращений учитываются
  с нулевым покрытием.

В охват входят `cmd/`, прикладные пакеты `internal/` и `pkg/`,
а также `frontend/src`. Из измерения исключены тесты, их инфраструктура,
зависимости и сгенерированный фронтенд-бандл. Интеграционные Go-тесты
работают с реальными PostgreSQL и Redis. Внешние HTTP-сервисы,
модель и граница доставки Kafka проверяются на контролируемых
ответах. Браузерные тесты проверяют интерфейс с имитацией HTTP и WebSocket.

Контракты и связь с проверками собраны в [SDD-060](specs/060-submission-test-coverage.md).
