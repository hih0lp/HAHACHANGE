# Отчёт об автоматических тестах

Проверено 10 ноября 2026 года на macOS arm64, Go 1.27.3, PostgreSQL 17. Ветка `codex/distributed`.

## Команды

```shell
PATH="/opt/homebrew/opt/postgresql@17/bin:$PATH" sh scripts/test-coverage.sh
go tool cover -func=/tmp/ai-buddy-coverage.out
```

## Результат

- Все Go-тесты прошли.
- Суммарное покрытие: **90,0%** по `go tool cover -func` (1227 из 1363 statements, 90,022%). До расширения тестов — 58,9%.
- Скрипт сам создал временную PostgreSQL и удалил её после тестов; каждому тесту выделена отдельная схема. PostgreSQL-интеграционные тесты в полном прогоне не пропускались.
- Dockerfile использует тот же скрипт с порогом 90%. Сам Docker-образ на Mac не собирался: daemon не запущен.

Новые проверки: сохранение и восстановление сценария, изоляция владельцев, конфликт ревизий, HTTP-форма и статус заявки, WebSocket-авторизация и завершение задания, outbox и откат транзакции при его недоступности, повторная доставка, ограниченные повторы ошибки модели, восстановление lease, защита от поздней записи старого воркера и неопределённый результат внешнего действия без повторной отправки. PostgreSQL настоящая; HTTP и broker fixtures используются только в тестовом процессе.

Профиль создаётся скриптом и доступен для воспроизведения. Порог покрытия относится к Go; выполнение браузерного JavaScript этим отчётом не измеряется. Сквозная работа с будущим сервисом SDD-007 и живой Kafka остаётся отдельной проверкой интеграции.
